# Min Webbplats
Webbplatsen jag skapat är för en lab uppgift, där då skapat tre olika sidor.  
Start sidan har lite information om mig och en bild,   
hobby sidan handlar om min hobby vilket är då att jag tittar på fotboll och vilket lag jag hejar på.  
Den sista sidan är då kontakt sidan där du kan fylla i ett formulär om vad personen vill kontakta mig om.

## Tekniker
* **HTML5:** Jag använde html5 för strukturen av sidan, till exempel listor i sidan hobby och formulär i kontakt sidan.  
* **CSS:** Använde css i form of <style> för att ändra färg på sidan och text, samt positionering av olika element.

## Svar På Frågor Om Git
1. git add lägger upp de ändrade filerna på staging area, och git commit sparar ändringarna i projekt historiken (med ett meddelande)
2. För att man vill alltid hålla main rent, main ska bara innehålla kod som är färdigt. Branches gör att man kan jobba på något nytt utan att skapa buggar och krascha sidan. Det är också till för att flera kan samarbeta på samma projekt utan att det skapar problem.
3. Ändringarna från branchen man mergear blir då sparade till main och gör det till den nya main koden.
4. GitHub är där vi har projektets repository, vilket är vår källkod. Om vi pushar till github gör det eventuella ändringar på koden och i vårt fall ändrar på webbsidans utseende. Pubblicera på t.ex. Netlify är för att skapa en live webbplats för besökare. 
5. Man skapar en textfil som heter .gitignore och skriver namn på filerna man vill dölja.
